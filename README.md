# Skills

[![skills.sh](https://skills.sh/b/johannhipp/skills)](https://skills.sh/johannhipp/skills)

These skills are meant to encode practical engineering judgment that agents can reuse across projects.

## Install

```bash
npx skills@latest add johannhipp/skills
```

## Why

This repo collects reusable guidance for choices that compound over time: API contracts, routing, server state, URL state, realtime, design systems, and other conventions that are cheap to set early and expensive to retrofit.

## Reference

- **[coss-svelte](./skills/coss-svelte/SKILL.md)** - Implement coss-svelte UI components correctly in Svelte and SvelteKit projects.
- **[early-frontend-architecture](./skills/early-frontend-architecture/SKILL.md)** - Set day-one frontend architecture decisions for young web apps before the codebase becomes large.
