# Skills

[![skills.sh](https://skills.sh/b/johannhipp/skill)](https://skills.sh/johannhipp/skills)

My agent skills for building and reviewing software projects.

These skills are meant to encode practical engineering judgment that agents can reuse across projects.

## Quickstart (30-second setup)

1. Run the skills.sh installer:

```bash
npx skills@latest add johannhipp/skill
```

2. Pick the skills you want, and which coding agents you want to install them on.

3. You are ready to go.

## Why these skills exist

Agents are more useful when the boring architectural decisions are explicit.

This repo collects reusable guidance for choices that compound over time: API contracts, routing, server state, URL state, realtime, design systems, and other conventions that are cheap to set early and expensive to retrofit.
